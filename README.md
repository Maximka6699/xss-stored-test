
# Stored XSS (Сохранённые межсайтовые сценарии)

Это веб-приложение с обсуждением, есть возможность оставлять комментарии. Для того, чтобы войти в начальный аккаунт нужно залогиниться (user1:1111). Админ проверяет комментарии каждые 5 секунд. Какой комментарий нужно оставить, стать админом? Имеется функционал смены пароля.

Для запуска веб-приложение нужно:

1. Клонировать репозиторий:

```
git clone https://github.com/Maximka6699/xss-stored-test.git
```

2. Перейти в диреторию с установленным репозиторием:

```
cd xss-stored-test
```

3. Построить и запустить образ докера:

```
sudo docker compose up --build
```

4. Перейти на сайт http://localhost:5000/
